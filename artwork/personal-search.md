# Zipp search placeholder source

The WootenLink search placeholder uses the official Zipp Storm detective artwork from *My Little Pony: Mane Merge* as a remote transparent PNG.

- Mirror: https://twibooru.org/2860403
- PNG: https://cdn.twibooru.org/img/2022/12/28/2860403/full.png
- Original reference: https://derpibooru.org/images/3015689

The image is not vendored into this repository. This placeholder is intended to establish the UI direction while the final MLP-themed search treatment is refined.
